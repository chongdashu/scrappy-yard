Owner prompts that steered the build

Chong-U (owner prompt) · premise card
Crash bandicoot x Mario 3d x Spyro style runner , running toward camera, mech in the background chasing you

Why it works: Sets genre, camera and threat in one line.

Chong-U (owner prompt) · mockup pick
D — Scrapyard neon

Why it works: One choice sets palette, hero and props.

Chong-U (owner prompt) · Tripo
you can autorig and then blender polish yeah don't overwrite the gym, but you need a character test scene to preview the animations etc.

Why it works: Approves the pipeline and asks for a safe preview space.

Chong-U (owner prompt) · asset policy
we should use image generation to create reference images for each of these items an then use tripo to generate them we can use blender for things we can model ourselves

Why it works: Generate what has character; model what is geometry.

Chong-U (owner prompt) · feel
can we make it less fixed 3 lane, and allow freedom of movement left and right, but obviously still keep the key collisions lane based

Why it works: Changes feel, keeps the rules readable.

Chong-U (owner prompt) · ElevenLabs
you should do all bgm for the main menu, the main game, and sfx for the game and menu

Why it works: A complete audio scope in one sentence.

Chong-U (owner prompt) · UI
let's redo the main menu to be more game like, look entirely different splash screen to menu should not have the current transition change sounds and when crashing i want a different sound than the clown sound

Why it works: Four concrete asks, all testable.

Chong-U (owner prompt) · marketing
ok install hyperframes and make a trailer of the game

Why it works: Install the tool and ship the thing in one ask.

Generator prompt patterns

Every image-to-3D reference prompt Grok Bot wrote follows the same shape. Full texts are on the Tripo and World pages.

PartWhat it says (from the saved prompts)
Purpose line"Character turnaround reference sheet for a 3D game asset pipeline (image-to-3D)."
Subject onlyONE object or character, with palette, materials and proportions spelled out
Compositionone row of front / 3/4 / side / back, or a single 3/4 view from about 20° above; wide gaps; whole object in frame
Pose (characters)A-pose, arms about 45° down, hands empty, legs apart, tail clear of the legs
Backdrop"Plain flat pale studio gray background (#D0D0D0)"; soft even light, no cast shadows
Style"stylized low-poly 3D toon game … render, flat colour with gentle cel shading" + "Match … Scrapyard neon direction D"
Exclusionsno green screen, no props in hands, no background, no text, no extra figures

Tripo text → model prompts were short by comparison, e.g. stylized cartoon rusted orange industrial gantry crane tower with lattice frame and hanging hook, scrapyard, hand-painted game asset, standalone.
