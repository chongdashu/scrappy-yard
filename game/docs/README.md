# Game documents

This game's own working documents. The steps fill this folder in:

| File | Written at | What it holds |
| --- | --- | --- |
| `asset-contract.md` | kickoff | The agreement every asset follows, copied from `docs/templates/asset-contract.md` |
| `vertical-slice-contract.md` | slice | The agreement for one playable round, copied from `docs/templates/vertical-slice-contract.md` |
| `upstream.md` | when the game adds an engine hook | One line per hook: the hook, the file and why (see `AGENTS.md`) |

Short notes of the game's own, such as the kickoff gym's rules, go here too.
The brief and the review pages are in `docs/`: `docs/brief.md` and
`docs/direction/`.
